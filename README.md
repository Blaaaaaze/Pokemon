# Проект Pokemon

Этот пет-проект подразумевается как файтинг-игра. Каким он будет в итоге, пока сложно сказать, но реализовываю его я в несколько этапов. Пока что история чистая клиентская, возможно в более поздних версиях появится серверная логика. На данный момент сделан первый этап - Pokedex

## Стек
* TypeScript
* React
* RTK
* React Router
* axios
* SCSS
